# Oil Spill Semantic Segmentation — Final Submission

## Package contents
- Models/: best saved weights for four experiments
- Experiments/: original metrics, source files and graphs
- Comparison/: results tables, prediction examples and HTML report
- Notebooks/: separately available team notebooks

## Important
The original dataset is not included.
Training is NOT rerun by the packaging script.
Results are taken from original saved test evaluations.
Cross-architecture evaluation has minor protocol differences.

## To view the report
Open Comparison/Final_Report.html in a browser.
Use Print -> Save as PDF for a PDF copy.

## Reproduction
Use the appropriate original model source/notebook,
configuration and dataset with the saved weights.
Weights are retained without modification.
